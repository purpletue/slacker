# Slacker

My slack bot who actually does slack off. every command might provide a response, might not. who knows? certainly not me.

## Features/Commands

Slacker has the following commands you can use anywhere in the hack club slack workspace:
/slacker-help shows this help message.
/slacker-int introduces the bot with a short description.
/slacker-joke to tell you a joke.
/slacker-fb sends feedback to me directly.
/slacker-ai sends a message to Gemini with a custom prompt to behave like slacker.

### How did i make this?
So i decided to make a slack bot one day, and i thought a cool gimmic might be that the bot really does ***slack*** off. i followed the hack club slack bot tutorial, learned how to make it write shit, how to access API's, and thats how i made the first revision. it had 3 commands: the help, the introduction, and the joke. i then thought it'd be good to be able to send me feedback on the bot, so i did some more digging online, and implemented that. after, i decided "yeah, lets make it AI. everything has AI nowadays so this should too.", did a lot more digging, found the main method, and thats how the current revision stands.
